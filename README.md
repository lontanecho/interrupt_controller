# TEC-8 中断版硬布线控制器

基于 TEC-8 教学计算机实验箱，在 EPM7128SLC84-15 CPLD 上用 Verilog 实现的带中断功能的硬布线控制器。

## 硬件环境

- 实验箱：TEC-8 教学计算机
- CPLD：EPM7128SLC84-15（84 脚 PLCC 封装）
- 开发工具：Quartus II 9.1

## 功能说明

在原版硬布线控制器基础上扩展了中断机制，支持以下功能：

- 按下 PULSE 按钮触发中断请求，机器在当前指令边界响应
- 中断响应后自动跳转到中断服务程序入口（由 R2 预置）
- 新增 RETI 指令（操作码 `1111`），从中断服务程序返回断点继续执行
- 中断允许标志 INTI_FLAG，响应中断后自动关闭，RETI 后重新开启

## 硬件约束与设计取舍

原版 TEC-8 通过 LIAR/IABUS 信号配合 IAR 寄存器保存断点，本实现中该信号未引出到 CPLD，采用以下替代方案：

**断点保存**：取指拍同时执行 PCINC 和 R3 自增，使 R3 始终跟踪当前指令地址。中断响应后 INTI_FLAG=0，R3 冻结保存断点；RETI 执行后 INTI_FLAG=1，R3 恢复同步。

**中断向量**：无法直接传送立即数到 PC，改由程序员在运行前将中断入口地址预置到 R2，中断响应时通过 ALU 直通 R2 写入 PC。

**PULSE 锁存**：PULSE 按下会触发 STOP 停止时序发生器，T3 不再产生，无法用边沿触发 flip-flop 采样。改用电平敏感 latch，PULSE 高电平期间直接置位 IS_INT 并保持，不依赖 T3 时钟。

## 使用方法

### 上机步骤

1. **预置寄存器**（SW=100 写寄存器模式）
   - R0、R1 写入初始值
   - R2 写入中断服务程序入口地址（如 `08H`）
   - R3 无需手动预置，由控制器自动同步

2. **写入程序**（SW=001 写存储器模式）
   - 从地址 00 开始写入主程序
   - 从中断入口地址（08H）写入中断服务程序，末尾为 RETI 指令

3. **初始化 PC**（SW=000 取指模式）
   - 按 QD，STOP 亮，将 SD 开关拨到起始地址
   - 再按 QD，PC 和 R3 初始化为 SD 值

4. **运行**
   - 单拍模式：每按一次 QD 执行一拍
   - 任意时刻按 PULSE，机器在当前指令边界响应中断，跳转到 R2 所指地址
   - 中断服务程序执行完 RETI 后自动返回断点

### 测试程序示例

| 地址 | 机器码 | 说明 |
|------|--------|------|
| 00   | 40     | INC R0（主程序循环计数） |
| 01   | 40     | INC R0 |
| 02   | 40     | INC R0 |
| 03   | 40     | INC R0 |
| 04   | 40     | INC R0 |
| 05   | 40     | INC R0 |
| 06   | E0     | STP（主程序结束） |
| 08   | 44     | INC R1（中断服务，R1 记录中断次数） |
| 09   | F0     | RETI（返回断点） |

预置 R2=08，运行过程中按 PULSE，RETI 后 R0 的值为被中断时执行到的地址，R1 累计中断次数。
